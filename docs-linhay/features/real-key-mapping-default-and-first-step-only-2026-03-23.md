# 真实键位映射默认策略（2026-03-23）

## 背景
用户要求按键映射更贴近真实键盘行为：按下即 keyDown、松开即 keyUp。
同时在串行步骤场景中，需要限制“真实映射”仅作用于首步骤，避免后续步骤被错误长按。

## 需求边界
1. 默认按键映射行为为“真实键位映射”（按下/抬起绑定输入生命周期）。
2. 串行步骤（2 步及以上）中，仅第 1 步允许走真实映射语义。
3. 第 2 步及以后始终为点按步骤（按下后立即抬起，按 delay 执行）。
4. 不新增持久化字段；复用既有步骤 `delayMilliseconds`。

## BDD 验收场景
### 场景 1：单步默认真实映射
- Given 用户新增第一条触发步骤
- When 步骤创建完成
- Then 该步骤默认 `delayMilliseconds = 0`
- And 触发语义为“长按/真实映射”

### 场景 2：多步仅首步真实
- Given 用户配置了两条及以上串行步骤
- When 第 1 步 `delayMilliseconds = 0`
- Then 第 1 步按真实映射语义执行（按下保持，释放时抬起）
- And 第 2 步及以后按点按语义执行

### 场景 3：首步可配置为点按
- Given 用户配置多步串行
- When 用户将第 1 步 delay 调整为大于 0
- Then 第 1 步改为点按语义
- And 后续步骤仍保持点按语义

## 验收标准
1. `NJOutputKeyPress` 运行时语义满足“首步可真实、后续点按”。
2. 编辑器“方式”列判定与运行时一致。
3. 新增/更新测试通过且全量测试通过。
