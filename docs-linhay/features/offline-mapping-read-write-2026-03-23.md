# 离线映射可读可配（2026-03-23）

## 背景
- 当前输出编辑器依赖在线设备输入节点。
- 设备离线后，已选输入会被清空，导致无法继续查看或调整该输入的映射。

## 目标
1. 设备离线后，保留当前选中输入 UID，不清空编辑上下文。
2. 离线状态下仍可查看该 UID 对应的映射（若无映射则显示空草稿）。
3. 离线状态下可继续配置并保存映射（按 UID 写入当前 mapping）。

## BDD 验收场景
1. Given 用户已选中某输入并配置映射
   When 设备断开
   Then 输出编辑器仍显示该输入路径与映射内容（离线）。
2. Given 设备离线且当前选中输入存在 UID
   When 用户修改输出类型或按键配置
   Then 配置可保存到当前 mapping 的该 UID 条目。
3. Given 用户手动取消选中输入
   When 选中为空
   Then 编辑器清空并恢复不可编辑状态。

## 验收标准
1. `NJMapping` 支持按 UID 直接读写输出条目。
2. Runtime 选择上下文在设备离线时不被强制清空。
3. 相关测试覆盖离线 UID 读写与路径展示逻辑。
