# 键位映射配置导入导出（2026-03-23）

## 背景
当前映射编辑能力完整，但缺少配置文件导入/导出，无法在设备之间复用映射配置。

## 需求边界
1. 支持导出整套映射配置为 JSON 文件（包含全部 mappings 与当前 selected）。
2. 支持从 JSON 文件导入整套映射配置并整体替换当前配置。
3. 导入后保持文件中的选中映射索引（越界时自动钳制到有效范围）。
4. 保持向后兼容：仍可导入旧版“仅 mappings 数组”格式。
5. 不改变单条映射序列化结构（仍沿用 `NJMapping.serialize()`）。

## BDD 验收场景
### 场景 1：导出整套映射
- Given 用户当前存在多条映射并有激活项
- When 用户触发“导出映射”并确认文件路径
- Then 系统写出包含 `format/version/mappings/selected` 的 JSON 文件

### 场景 2：导入整套映射
- Given 用户触发“导入映射”并选择有效 JSON 文件
- When 系统解析成功
- Then 系统替换当前映射配置并刷新 UI 状态
- And 激活项与文件 `selected` 一致（越界则钳制）

### 场景 3：无效文件导入失败
- Given 用户选择了无效映射文件
- When 系统解析文件
- Then 不改变现有映射列表
- And 记录失败信息（日志/错误提示）

## 验收标准
1. Root Feature 暴露 `import/export` 对应 action，且可调用 runtime。
2. 映射管理 UI 提供导入与导出入口。
3. 相关测试覆盖导入导出调用链与关键输入行为，且全量测试通过。
