## Delete 键映射误删整句修复（17:43）
- 用户反馈：映射 `Delete` 后触发时出现“整句删除”，非逐字回删。
- 结论：`NJOutputKeyPress` 对非修饰键事件未显式规范 flags，存在修饰位污染风险。
- 修复：
  - `NJOutputKeyPress` 新增 `eventFlagsForStep(_:keyDown:)`，按步骤 keys 显式计算 `maskCommand/maskAlternate/maskControl/maskShift/maskAlphaShift`。
  - 对非修饰键发送事件时使用该 flags，避免单键 `Delete` 误带修饰位。
  - `Fn` 仅在 keyDown 注入 `maskSecondaryFn`，keyUp 移除，避免粘连。
- 测试（TDD）：
  - `KeyPressThresholdTests` 新增 3 个用例：
    1. 单键 `Delete` flags 为空；
    2. `⌘ + Delete` 包含 `maskCommand`；
    3. `Fn + Delete` 仅 keyDown 带 `maskSecondaryFn`。
- 文档：新增 `docs-linhay/features/delete-key-mapping-flags-fix-2026-03-23.md`。
- 验证：`swift test` 全量通过（117 tests, 0 failed）。
