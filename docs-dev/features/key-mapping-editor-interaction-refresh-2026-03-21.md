# 按键详情编辑器交互重构（2026-03-21）

## 背景
当前按键详情页功能可用，但交互层级仍偏“单表单堆叠”，与“源输入诊断 + 配置操作”的心智模型不一致。需要按交互指南重构为更清晰的信息架构，并减少误操作风险。

## 需求边界
1. 仅调整 `AppleKeyMappingEditorSheet` 的交互结构与状态反馈，不修改 HID 核心映射逻辑。
2. 保留现有能力：启用开关、键位编辑、阈值调节、宏步骤编辑、保存/取消。
3. 增加取消时的未保存变更保护，避免误关弹窗导致配置丢失。
4. 保持 macOS 11 兼容。

## BDD 验收场景

### 场景 1：双栏信息架构
- Given 用户打开按键详情页
- When 页面渲染
- Then 左栏展示“源输入 + 诊断信息”
- And 右栏展示“可编辑配置表单”

### 场景 2：不可解析输入的明确反馈
- Given 当前控件不可解析
- When 页面渲染
- Then 保存按钮不可用
- And 页面显示不可编辑原因

### 场景 3：取消时防误操作
- Given 用户已修改任一字段但尚未保存
- When 点击取消
- Then 弹出放弃修改确认
- And 用户可选择“继续编辑”或“放弃更改”

### 场景 4：编辑控件可用性一致
- Given 页面处于禁用或不可解析状态
- When 用户尝试编辑阈值与宏步骤
- Then 相关控件被禁用
- And 宏“移除步骤”在步骤数小于等于 1 时不可用

## 非目标
1. 不引入新的持久化字段。
2. 不改动输出序列化格式。
3. 不新增复杂动画。

## 二次重构验收补充（按键详情页）

### 场景 5：编辑流程单路径
- Given 用户打开按键详情页
- When 查看页面主结构
- Then 页面使用单一路径编辑流（源输入状态 -> 绑定编辑 -> 宏步骤）
- And 不再出现可拖拽双栏导致的焦点与滚动竞争

### 场景 6：保存可用性与编辑状态一致
- Given 用户启用该映射但未配置任何有效按键
- When 用户尝试保存
- Then 保存按钮不可用
- And 页面提示“需先配置按键或关闭启用”

### 场景 7：宏步骤空态文案正确
- Given 宏步骤列表为空
- When 页面渲染宏编辑区
- Then 显示宏编辑空态提示
- And 不复用与轴值无关的提示文案

## 二次收敛（2026-03-21 02:00）
1. 左栏固定宽度（源输入/诊断），右栏编辑区随窗口拉伸。
2. 右栏编辑项采用统一标签列宽与冒号风格，提升 macOS 偏好设置式可读性。
3. 宏步骤行改为“步骤 N”标签，增强行语义。

## 三次收敛：两张语义卡 + 组合键双轨（2026-03-22）

### 场景 8：右侧两张语义卡
- Given 用户打开按键详情页
- When 查看右侧编辑区
- Then 以“按钮状态”卡与“触发事件”卡呈现，不再是单一大表单
- And 左侧“源输入/诊断”不变

### 场景 9：触发事件支持单键/组合键双轨
- Given 用户编辑触发事件步骤
- When 切换步骤类型为“单键”或“组合键”
- Then 每一步可配置一个按键或多个组合键
- And 步骤延时、新增、删除、上下移动仍可用

### 场景 10：新旧序列化兼容与一次性迁移
- Given 历史配置使用旧 `key/sequence` 字段
- When 系统读取并保存
- Then 能正确读取旧数据并转换为新 `steps` 结构
- And 后续仅写入新结构

### 场景 11：模拟轴映射按键应保持长按（非连发）
- Given 用户将模拟轴输入映射到按键输出
- When 轴值持续高于触发阈值
- Then 目标按键保持按下状态直到轴值回落
- And 不进行自动连发
- And 在“单步且延时为 0”场景下，组合键同样保持按下并在释放时整体抬起

### 场景 12：长按与点按语义可视区分
- Given 用户在触发事件卡编辑步骤
- When 查看每一步的行为标识
- Then 能明确看到该配置当前是“长按”还是“点按”
- And 标识与真实触发语义保持一致
